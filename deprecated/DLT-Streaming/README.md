# DLT / Streaming

Delta Live Tables (Lakeflow Declarative Pipelines) and streaming examples — declarative
pipelines in Python and SQL, event-log inspection, and publishing modes.

| File | Type | Description |
|------|------|-------------|
| `01 - DLT Football (Python).py` | Python | DLT pipeline over football data (Python API). |
| `02 - DLT Football (SQL).sql` | SQL | Same pipeline expressed in DLT SQL. |
| `03 - DLT Demo (dbdemos).py` | Python | DLT demo based on the `dbdemos` sample. |
| `04 - DLT Event Logs.sql` | SQL | Query the DLT event log for pipeline observability. |
| `05 - Direct Publish Mode.py` | Python | DLT direct publish mode. |
| `06 - Query Pipeline Results.sql` | SQL | Query tables materialized by a DLT pipeline. |
| `07 - DLT Quickstart (Baby Names).sql` | SQL | Quickstart DLT pipeline using the baby-names dataset. |
