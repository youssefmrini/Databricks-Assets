# ML / MLOps

Machine learning and MLOps on Databricks: MLflow, Unity Catalog model registry,
feature engineering, AutoML, and end-to-end examples.

| File | Description |
|------|-------------|
| `Introduction MlFLow.py` | Introduction to MLflow tracking and models. |
| `MLflow Model Training Overview.py` | Overview of training and logging models with MLflow. |
| `Training.py` | Model training walkthrough. |
| `Feature engineering with Unity Catalog.py` | Feature engineering using the Unity Catalog feature store. |
| `machine-learning-with-unity-catalog.py` | End-to-end ML with models governed by Unity Catalog. |
| `mlflow-end-to-end-example-uc.py` | End-to-end MLflow example registering models in UC. |
| `Upload to model to UC.py` | Register/upload a model to the Unity Catalog model registry. |
| `automl-forecasting-example.py` | AutoML forecasting example. |
| `HLS readmission.py` | Healthcare (HLS) hospital readmission prediction example. |
