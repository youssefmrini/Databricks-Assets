# Features

Focused, self-contained notebooks demonstrating specific newer Databricks features,
grouped by area. Each subfolder has its own README.

| Folder | Contents |
|--------|----------|
| [`apache-iceberg/`](apache-iceberg/) | Apache Iceberg V3 lifecycle, Variant on Iceberg, liquid clustering, UniForm V3, row-level concurrency, managed Iceberg tables. |
| [`delta-lake/`](delta-lake/) | SQL scripting, query tags, vacuum guardrails, partition materialization, type widening on streams, variant shredding, automatic liquid clustering. |
