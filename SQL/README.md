# SQL

Databricks SQL notebooks and scripts: SQL scripting, warehouse optimization,
system-table cost/audit analysis, connectors, and Genie setup.

| File | Type | Description |
|------|------|-------------|
| `01 - SQL Variables.sql` | SQL | Declaring and using session variables in Databricks SQL. |
| `02 - Warehouse Optimization.sql` | SQL | Tuning SQL warehouses for cost and performance. |
| `03 - System Tables Cost Analysis.py` | Python | Cost analysis queries over Unity Catalog system tables. |
| `04 - Audit Log Queries.sql` | SQL | Audit-log queries against system tables. |
| `05 - SQL Scripting Lab.sql` | SQL | SQL scripting lab — compound statements, control flow, loops. |
| `06 - SQLAlchemy Connector.py` | Python | Connecting to Databricks SQL via the SQLAlchemy connector. |
| `07 - Genie Setup.sql` | SQL | Provisioning and configuring a Genie space via SQL. |
| `AI Functions.sql` | SQL | Built-in AI functions (`ai_analyze_sentiment`, `ai_extract`, `ai_classify`, `ai_gen`, `ai_mask`, `ai_summarize`, `ai_translate`) for in-SQL text analytics. |
| `Lab_SQL_Scripting.sql` | SQL | SQL scripting lab: variables, `BEGIN`/`END`, `IF`/`ELSE`, `WHILE`/`FOR`, cursors, exception handling, dynamic SQL — a foundation for stored procedures. |
